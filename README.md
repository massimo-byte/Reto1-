Tarea: Realizar una Tienda Online con una Base de Datos Relacional en MySQL desde cero.
Objetivo en RETO 1: Hacer un Esquema de Base de Datos Relacional para la Escuela donde el Alumnado pueda indicar sus necesidades de Material educativo.
Se crearon 4 Entidades: Productos, Clientes, Pedidos y Detalle de Pedidos
Se definieron los atributos necesarios para cada Entidad
Se diseño el Esquema y las tablas y las relaciones entre ellas, incluyendo restricciones de integridad como claves primarias y foraneas u otras.
